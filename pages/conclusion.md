# 经典模型，持续进化

LSTM 诞生于 1997 年，Transformer 诞生于 2017 年。我们今天看到的研究成果，都建立在这些经典架构之上。

学者们并没有抛弃它们，而是不断为其注入新的活力：提出变体、融合方法、针对能源数据的特性加以改造。
经典之所以是经典，正是因为它们解决的是真实问题的本质。

# 智慧能源赋能深度学习

负荷预测、风电出力、用电异常检测……
每一类问题都有最适合它的模型结构。

但无论选择哪种方法，目标始终一致：
- 让能源系统**更高效、更稳定、更少浪费**
- 让可再生能源真正成为可以依赖的力量

深度学习在这里不是目的，而是手段。
它的意义，在于让智慧能源离现实更近一步。
