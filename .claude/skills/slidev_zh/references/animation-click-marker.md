# Click 标记

根据点击进度高亮并自动滚动演讲者备注。

## 语法

在演讲者备注中加入 `[click]` 标记：

```md
<!--
第一次点击前的内容

[click] 这部分会在第一次点击后高亮

这一段也会在第一次点击后高亮

- [click] 这个列表项会在第二次点击后高亮

[click:3] 最后一次点击（跳过前两次点击）
-->
```

## 行为

- 标记之间的备注会与幻灯片点击进度同步高亮
- 演讲者视图会自动滚动到当前激活的部分
- 使用 `[click:{n}]` 可以跳到指定点击编号

## 要求

- 仅在演讲者模式下生效
- 备注必须是放在幻灯片结尾的 HTML 注释
